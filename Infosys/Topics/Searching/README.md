# Searching

This module covers **Searching Algorithms**, primarily focusing on **Binary Search** and its advanced variants. Binary Search is the most heavily tested algorithmic concept in the Infosys Specialist Programmer (SP) and Digital Specialist Engineer (DSE) rounds.

If an array is sorted, or if a function is monotonic (continually increasing/decreasing), you should immediately think of Binary Search ($O(\log N)$).

## Key Patterns
- **Classic Binary Search:** Finding a target in a sorted array.
- **Lower/Upper Bound:** Finding the first or last occurrence of an element.
- **Rotated Arrays:** Finding elements or minimums when the sorted array is shifted.
- **Search Space on Answers:** (Advanced) When the array is not sorted, but the *range of possible answers* is sorted (e.g., Koko Eating Bananas, Allocate Books).
