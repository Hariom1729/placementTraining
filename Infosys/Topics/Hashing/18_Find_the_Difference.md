# Find the Difference

## Difficulty
Easy

## Probability
★★★★★

## Asked In
Infosys SP
Infosys DSE
Similar Companies: Amazon, Google

## Topic
Hashing / Bit Manipulation / Strings

## Pattern
Frequency Array / XOR

## Problem Statement
You are given two strings `s` and `t`.
String `t` is generated by random shuffling string `s` and then adding one more letter at a random position.
Return the letter that was added to `t`.

## Constraints
- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.

## Input
- `s` string.
- `t` string.

## Output
- Return a character.

## Sample Test Cases

**Example 1:**
```
Input: s = "abcd", t = "abcde"
Output: "e"
Explanation: 'e' is the letter that was added.
```

**Example 2:**
```
Input: s = "", t = "y"
Output: "y"
```

## Edge Cases
- `s` is empty (return the only char in `t`).
- The added character is a duplicate of a character already in `s`. (e.g., `s = "a"`, `t = "aa"`).

## Intuition
We have two collections of items. One collection has exactly 1 extra item. How do we find it?
**Approach 1: Hashing.**
Count the frequencies of all characters in `s`.
Then, subtract the frequencies as you iterate through `t`. The character that causes its frequency to drop below `0` is the extra character!

**Approach 2: Bit Manipulation (XOR).**
This is identical to the "Single Number" problem!
If we combine string `s` and string `t` into one giant array of characters, every character will appear exactly an EVEN number of times, EXCEPT for the one character that was added!
Since `X ^ X = 0` and `X ^ 0 = X`, if we XOR every character in `s` and every character in `t` together, all the duplicates will cancel each other out to `0`, leaving only the added character!

Both approaches are $O(N)$ time and $O(1)$ space. The XOR approach is faster in practice and flexes strong CS fundamentals.

## Optimal Approach 1 (Hash / Frequency Array)
**Detailed explanation:**
1. Create `vector<int> count(26, 0)`.
2. Iterate `c` in `s`: `count[c - 'a']++`.
3. Iterate `c` in `t`:
   - `count[c - 'a']--`.
   - If `count[c - 'a'] < 0`: return `c`.
4. Fallback return `' '`.

**Time Complexity:** $O(N)$
**Space Complexity:** $O(1)$

## Optimal Approach 2 (XOR)
**Detailed explanation:**
1. Initialize `char res = 0`.
2. For each `c` in `s`: `res ^= c`.
3. For each `c` in `t`: `res ^= c`.
4. Return `res`.

**Time Complexity:** $O(N)$
**Space Complexity:** $O(1)$

## C++ Solution (XOR - Most Optimal)

```cpp
#include <string>
using namespace std;

class Solution {
public:
    char findTheDifference(string s, string t) {
        char result = 0;
        
        // XOR all characters in s
        for (char c : s) {
            result ^= c;
        }
        
        // XOR all characters in t
        for (char c : t) {
            result ^= c;
        }
        
        // All matching characters cancel out to 0. 
        // The only one left is the extra character!
        return result;
    }
};
```

## C++ Solution (Frequency Array)

```cpp
class Solution {
public:
    char findTheDifference(string s, string t) {
        int count[26] = {0};
        
        for (char c : s) {
            count[c - 'a']++;
        }
        
        for (char c : t) {
            count[c - 'a']--;
            if (count[c - 'a'] < 0) {
                return c;
            }
        }
        
        return ' ';
    }
};
```

## Dry Run (XOR)
`s = "abcd", t = "abcde"`
- `result = 0`
- XOR `s`: `result = 0 ^ 'a' ^ 'b' ^ 'c' ^ 'd'`
- XOR `t`: `result = ('a'^'b'^'c'^'d') ^ 'a' ^ 'b' ^ 'c' ^ 'd' ^ 'e'`
- Reorder terms: `('a'^'a') ^ ('b'^'b') ^ ('c'^'c') ^ ('d'^'d') ^ 'e'`
- `0 ^ 0 ^ 0 ^ 0 ^ 'e'`
- Returns `'e'`.

## Common Mistakes
- **Sorting both strings:** Sorting takes $O(N \log N)$ and modifying the strings is unnecessary. Use XOR for $O(N)$ speed and $O(1)$ space.
