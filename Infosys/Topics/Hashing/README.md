# Hashing

This module covers **Hashing** and **Hash Tables**, one of the most frequently tested data structures in the Infosys SP and DSE rounds due to its $O(1)$ lookup time.

## Key Patterns
- Frequency Counting (using `unordered_map`)
- Presence Checking (using `unordered_set`)
- Pair / Tuple matching (e.g., Two Sum variants)
- Hash maps for custom state tracking
