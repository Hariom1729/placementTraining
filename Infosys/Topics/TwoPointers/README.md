# Two Pointers

This module covers the **Two Pointers** technique, a crucial algorithmic paradigm for solving problems in arrays and strings. It is extremely common in Infosys SP and DSE interviews because it elegantly reduces time complexities, often from $O(N^2)$ to $O(N)$.

## Key Patterns
- **Opposite Ends (Collision):** One pointer starts at the beginning, one at the end, and they move towards the center (e.g., Valid Palindrome, Container With Most Water, 3Sum). Requires a sorted array or specific geometric properties.
- **Same Direction (Fast/Slow Pointers):** Both pointers start at the beginning but move at different speeds (e.g., Removing Duplicates, Linked List Cycle).
- **Partitioning:** Using pointers to segregate elements (e.g., Dutch National Flag / Sort Colors).
