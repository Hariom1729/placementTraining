# 3Sum

## Difficulty
Medium

## Probability
★★★★★

## Asked In
Infosys SP

Related Companies: Amazon, Meta, Microsoft

## Topic
Arrays

## Pattern
Two Pointers / Sorting

## Problem Statement
Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`.
Notice that the solution set must not contain duplicate triplets.

## Constraints
- $3 \le nums.length \le 3000$
- $-10^5 \le nums[i] \le 10^5$

## Input Format
- First line: `N`
- Second line: `N` space-separated integers.

## Output Format
- Return a 2D array representing the triplets.

## Sample Input
```
6
-1 0 1 2 -1 -4
```

## Sample Output
```
[[-1,-1,2],[-1,0,1]]
```

## Edge Cases
- Array consisting of all zeros (e.g., `[0, 0, 0, 0]`). Should return a single `[[0, 0, 0]]`.
- No valid triplets exist. Should return `[]`.

## Approach 1
Brute Force
**Explanation:** Use three nested loops to check every possible triplet. Use a Hash Set to store the sorted triplets and remove duplicates.
**Time Complexity:** $O(N^3)$ (Will TLE).
**Space Complexity:** $O(\text{Number of Unique Triplets})$

## Approach 2
Better Approach (Two Loops + Hash Set)
**Explanation:** Use two nested loops to fix two numbers. Check if the complement `-(nums[i] + nums[j])` exists in a hash map. Still requires a set to deduplicate.
**Complexity:** $O(N^2 \log (\text{set insertions}))$ time, $O(N)$ space.

## Approach 3
Optimal Approach (Sorting + Two Pointers)
**Explanation:** 
1. Sort the array.
2. Iterate through the array with index `i`. This fixes the first number of our triplet.
3. To prevent duplicate triplets, if `nums[i] == nums[i-1]`, we `continue` to the next iteration.
4. We now need to find two numbers that sum to `-nums[i]`. We can use the standard Two Pointers technique on the remaining array (`left = i+1`, `right = n-1`).
5. If `nums[left] + nums[right] == -nums[i]`, we found a triplet! Add it to the result.
6. Then, increment `left` and decrement `right`. To avoid duplicates for the second and third numbers, skip over identical values for both `left` and `right`.
7. If the sum is too small, increment `left`. If it's too large, decrement `right`.

**Time Complexity:** $O(N \log N)$ for sorting + $O(N^2)$ for the nested loops = $O(N^2)$.
**Space Complexity:** $O(1)$ auxiliary space (ignoring the space required for output).

## Java Solution
```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);
        
        for (int i = 0; i < nums.length - 2; i++) {
            // Skip duplicates for the first element
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            int left = i + 1;
            int right = nums.length - 1;
            
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                
                if (sum == 0) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    
                    // Skip duplicates for the second element
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    // Skip duplicates for the third element
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    
                    left++;
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        
        return result;
    }
}
```

## Python Solution
```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        res = []
        nums.sort()
        
        for i in range(len(nums) - 2):
            if i > 0 and nums[i] == nums[i-1]:
                continue
                
            left, right = i + 1, len(nums) - 1
            
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                
                if total == 0:
                    res.append([nums[i], nums[left], nums[right]])
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                    left += 1
                    right -= 1
                elif total < 0:
                    left += 1
                else:
                    right -= 1
                    
        return res
```

## C++ Solution
```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());
        
        for (int i = 0; i < nums.size() - 2; i++) {
            // Avoid duplicates for the first number
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            int left = i + 1;
            int right = nums.size() - 1;
            
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                
                if (sum == 0) {
                    result.push_back({nums[i], nums[left], nums[right]});
                    
                    // Avoid duplicates for the second and third numbers
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    
                    left++;
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        
        return result;
    }
};
```

## Common Mistakes
- **Using a Set for Deduplication:** Using `set<vector<int>>` to remove duplicates works, but it causes overhead and can TLE on stricter platforms. Skipping duplicates manually using `while (nums[left] == nums[left+1])` is faster and highly preferred.
- **Forgetting to advance pointers after finding a sum:** If `sum == 0`, you must advance BOTH `left` and `right` after handling duplicates. Otherwise, you hit an infinite loop.

## Interview Tips
- Mentioning why the array is sorted is critical: "Sorting allows us to use the Two Pointer approach to find the remaining two numbers in $O(N)$ time instead of $O(N^2)$, bringing total time to $O(N^2)$."
