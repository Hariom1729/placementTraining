# Sum Root to Leaf Numbers

## Difficulty
Medium

## Probability
★★★★☆

## Asked In
Infosys SP
Similar Companies: Amazon, Microsoft, ByteDance

## Topic
Trees

## Pattern
DFS / Backtracking

## Problem Statement
You are given the `root` of a binary tree containing digits from `0` to `9` only.
Each root-to-leaf path in the tree represents a number.
For example, the root-to-leaf path `1 -> 2 -> 3` represents the number `123`.
Return the total sum of all root-to-leaf numbers. Test cases are generated so that the answer will fit in a 32-bit integer.
A leaf node is a node with no children.

## Constraints
- The number of nodes in the tree is in the range `[1, 1000]`.
- `0 <= Node.val <= 9`
- The depth of the tree will not exceed `10`.

## Input
- `root` pointer of the Binary Tree.

## Output
- Return an integer representing the total sum.

## Sample Test Cases

**Example 1:**
```
Input: root = [1,2,3]
Output: 25
Explanation:
The root-to-leaf path 1->2 represents the number 12.
The root-to-leaf path 1->3 represents the number 13.
Therefore, sum = 12 + 13 = 25.
```

**Example 2:**
```
Input: root = [4,9,0,5,1]
Output: 1026
Explanation:
The root-to-leaf path 4->9->5 represents the number 495.
The root-to-leaf path 4->9->1 represents the number 491.
The root-to-leaf path 4->0 represents the number 40.
Therefore, sum = 495 + 491 + 40 = 1026.
```

## Edge Cases
- Tree has only one node. The sum is just the value of the root.
- The path numbers have leading zeros (e.g., node value is `0`). Mathematically, `current * 10 + 0` handles this perfectly without string parsing.

## Intuition
This is a standard Depth-First Search (DFS) problem. We can pass a `currentSum` variable down the recursion tree.
Every time we visit a new node, the path number constructed so far gets shifted to the left by one decimal place, and we add the current node's value.
Mathematically, this is: `currentSum = currentSum * 10 + root->val`.
When we reach a leaf node (both children are null), the `currentSum` is fully formed for that path, so we return it!
If we are at an internal node, the total sum for this subtree is simply the sum of the numbers generated by its left and right subtrees.

## Brute Force Approach
**Explanation:** Convert the paths into strings like `"495"`, store them in an array, then iterate through the array, convert strings to integers (`stoi`), and sum them up.
**Time Complexity:** $O(N)$
**Space Complexity:** $O(N)$ for string allocations and storage.

## Optimal Approach (Integer DFS)
**Detailed explanation:**
1. Define a recursive helper function `dfs(TreeNode* root, int currentSum)`.
2. **Base Case:** If `root == nullptr`, return `0`.
3. Update the sum: `currentSum = currentSum * 10 + root->val`.
4. **Leaf Node Check:** If `root->left == nullptr` and `root->right == nullptr`, we have reached a leaf. Return the `currentSum`.
5. **Recursive Step:** If it's not a leaf, recurse on both children and return their sum:
   `return dfs(root->left, currentSum) + dfs(root->right, currentSum)`.

**Time Complexity:** $O(N)$ because every node is visited exactly once.
**Space Complexity:** $O(H)$ where $H$ is the height of the tree for the recursion stack. (Max depth is 10, so space is effectively $O(1)$).

## C++ Solution

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        return dfs(root, 0);
    }
    
private:
    int dfs(TreeNode* root, int currentSum) {
        if (root == nullptr) {
            return 0;
        }
        
        // Update the current number being formed
        currentSum = currentSum * 10 + root->val;
        
        // If it is a leaf node, return the fully formed number
        if (root->left == nullptr && root->right == nullptr) {
            return currentSum;
        }
        
        // If not a leaf, recurse left and right and sum their results
        return dfs(root->left, currentSum) + dfs(root->right, currentSum);
    }
};
```

## Dry Run
Tree: `[4, 9, 0, 5, 1]`
- `dfs(4, 0)`
  - `curr = 0 * 10 + 4 = 4`.
  - Not leaf. Calls `dfs(9, 4)` and `dfs(0, 4)`.
  - `dfs(9, 4)`
    - `curr = 4 * 10 + 9 = 49`.
    - Not leaf. Calls `dfs(5, 49)` and `dfs(1, 49)`.
    - `dfs(5, 49)` -> `curr = 495`. Leaf! Returns `495`.
    - `dfs(1, 49)` -> `curr = 491`. Leaf! Returns `491`.
    - Node 9 returns `495 + 491 = 986`.
  - `dfs(0, 4)`
    - `curr = 4 * 10 + 0 = 40`.
    - Leaf! Returns `40`.
  - Node 4 returns `986 + 40 = 1026`.
Result: `1026`.

## Common Mistakes
- **Returning 0 for null nodes incorrectly:** If you use a global variable to add sums, you have to be careful not to double-count leaves. Returning `0` for `nullptr` combined with the leaf check `(left == null && right == null)` perfectly avoids double-counting! If you omitted the leaf check, a leaf node like `5` would return `dfs(null, 495) + dfs(null, 495) = 495 + 495`, doubling your answer! The leaf check prevents this.
