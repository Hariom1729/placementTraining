## 🌟 About This Repository

This repository is built to be the single source of truth for your TCS NQT 2027 preparation. Unlike scattered resources across the internet, this repo provides **structured, high-yield, and complete** educational content. 

Whether you are aiming for **Ninja (3.36 LPA)**, **Digital (7.0 LPA)**, or **Prime (9.0 LPA)**, this repository covers the exact breadth and depth required to crack the exam and subsequent interviews.

### Key Features
- **Comprehensive Theory & Explanations:** Deep dives into every DSA and CS Fundamental topic.
- **Curated Problem Sets:** Hundreds of TCS-specific previous year questions (PYQs) and expected questions.
- **Optimized Solutions:** Solutions written in Java/C++ with time and space complexity analysis.
- **Pattern Recognition:** Frameworks to identify problem patterns rather than just memorizing solutions.
- **End-to-End Preparation:** Covers Aptitude, Reasoning, Verbal, DSA, CS Fundamentals, and HR.

## 🗺️ Roadmap

To maximize your chances, follow this structured roadmap:

### Phase 1: Foundation (Weeks 1-3)
1. **Programming Language Mastery:** Choose Java or C++. Master loops, functions, basic OOP, and Collections/STL.
2. **Quantitative Aptitude Basics:** Number System, Percentages, Profit & Loss, Speed/Time/Distance.
3. **Logical Reasoning:** Blood Relations, Seating Arrangements, Coding-Decoding.

### Phase 2: Core DSA (Weeks 4-8)
1. **Arrays & Strings:** Two Pointers, Sliding Window, Prefix Sum.
2. **Searching & Sorting:** Binary Search on Answer, Merge Sort, Quick Sort.
3. **Hashing & Linked Lists:** HashMaps, Cycle Detection, Reversal.
4. **Recursion & Backtracking:** Subset Generation, Permutations.

### Phase 3: Advanced DSA & CS Fundamentals (Weeks 9-12)
1. **Trees & Graphs:** BFS, DFS, Shortest Path algorithms, BST properties.
2. **Dynamic Programming:** 1D DP, Knapsack, LCS (Crucial for Prime).
3. **CS Fundamentals:** Object-Oriented Programming (OOP), Database Management Systems (DBMS), Operating Systems (OS), Computer Networks (CN).

### Phase 4: Mock Tests & Interviews (Weeks 13-14)
1. **Timed Mocks:** Practice TCS NQT patterned mock tests.
2. **Technical Interviews:** Revise CS core subjects and practice explaining your code.
3. **HR Interviews:** Prepare standard situational and behavioral questions.

## 📅 Study Plan

### The 90-Day Comprehensive Strategy

| Days | Focus Area | Detailed Plan |
|---|---|---|
| **01-15** | Aptitude & Reasoning | 2 hours Quant, 1 hour Reasoning daily. Focus on building speed and learning shortcuts. |
| **16-30** | Arrays, Strings, Hashing | 3 hours DSA daily. Solve at least 5 problems/day. Learn Kadane's, Two Pointers, Sliding Window. |
| **31-45** | Linked List, Stack, Queue | Understand dynamic memory, stack-based parenthesis, NGE (Next Greater Element) patterns. |
| **46-60** | Trees, Graphs, Recursion | Focus on traversals (In/Pre/Post), BFS/DFS, and recursive tree building. Essential for Digital. |
| **61-75** | CS Fundamentals | 2 hours daily on OOP, DBMS (SQL Queries), OS (Deadlocks, Paging), CN (OSI Model). |
| **76-85** | Verbal & Coding Revision | Brush up grammar, RC. Revise all DSA patterns. Solve hard Prime-level coding questions. |
| **86-90** | Mock Interviews | Practice "Tell me about yourself", project explanations, and give full-length mock tests. |
