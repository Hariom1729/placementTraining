# Problem 28: 3 Sum

## Problem Statement
Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`.
Notice that the solution set must not contain duplicate triplets.

## Input Format
- An array of integers `nums`.

## Output Format
- A 2D array containing the unique triplets.

## Constraints
- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

---

## Approach

**Optimal Approach: Sorting + Two Pointers**
1. **Sort the array:** This helps in avoiding duplicates and applying the Two-Pointer technique.
2. Iterate `i` from `0` to `n-3`. This is the first element of our triplet.
3. **Skip duplicates for `i`:** If `i > 0` and `nums[i] == nums[i-1]`, skip to the next iteration.
4. Let the required sum for the remaining two elements be `target = 0 - nums[i]`.
5. Set `low = i + 1` and `high = n - 1`.
6. While `low < high`:
   - If `nums[low] + nums[high] == target`, we found a triplet. Add it to results.
   - **Skip duplicates for `low` and `high`** by advancing the pointers until the values change. Then do `low++` and `high--`.
   - If the sum is `< target`, `low++` (we need a bigger value).
   - If the sum is `> target`, `high--` (we need a smaller value).

---

## C++ Solution

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> res;
        int n = nums.size();
        
        for (int i = 0; i < n - 2; i++) {
            // Skip duplicates for the first element
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            int lo = i + 1;
            int hi = n - 1;
            int target = -nums[i];
            
            while (lo < hi) {
                if (nums[lo] + nums[hi] == target) {
                    res.push_back({nums[i], nums[lo], nums[hi]});
                    
                    // Skip duplicates for the second element
                    while (lo < hi && nums[lo] == nums[lo + 1]) lo++;
                    // Skip duplicates for the third element
                    while (lo < hi && nums[hi] == nums[hi - 1]) hi--;
                    
                    lo++;
                    hi--;
                } else if (nums[lo] + nums[hi] < target) {
                    lo++;
                } else {
                    hi--;
                }
            }
        }
        return res;
    }
};

int main() {
    Solution sol;
    vector<int> nums = {-1, 0, 1, 2, -1, -4};
    vector<vector<int>> res = sol.threeSum(nums);
    
    for (auto& triplet : res) {
        cout << "[" << triplet[0] << ", " << triplet[1] << ", " << triplet[2] << "]\n";
    }
    // Expected output:
    // [-1, -1, 2]
    // [-1, 0, 1]
    
    return 0;
}
```

---

## Complexity Analysis

- **Time Complexity:** `O(N^2)`. Sorting takes `O(N log N)`. The outer loop runs `N` times, and the inner `while` loop runs at most `N` times. Overall `O(N^2)`.
- **Space Complexity:** `O(1)` auxiliary space (ignoring the space required for output).
