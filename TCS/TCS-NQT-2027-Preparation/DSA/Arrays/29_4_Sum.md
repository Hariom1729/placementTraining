# Problem 29: 4 Sum

## Problem Statement
Given an array `nums` of `n` integers, return an array of all the unique quadruplets `[nums[a], nums[b], nums[c], nums[d]]` such that:
- `0 <= a, b, c, d < n`
- `a`, `b`, `c`, and `d` are distinct.
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

You may return the answer in any order.

## Input Format
- An array of integers `nums`.
- An integer `target`.

## Output Format
- A 2D array containing the unique quadruplets.

## Constraints
- `1 <= nums.length <= 200`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`

---

## Approach

This is an extension of the **3 Sum** problem.
1. Sort the array.
2. Use two nested loops for the first two elements (`i` and `j`).
3. For the remaining two elements, use the **Two-Pointer** approach (`front = j + 1` and `back = n - 1`).
4. **Crucial:** Because constraints on `nums[i]` and `target` are up to `10^9`, adding 4 elements can easily exceed the standard 32-bit `int` capacity (`INT_MAX` is ~`2 * 10^9`). You MUST use `long long` for sum calculations in C++ to avoid overflow errors on Leetcode/TCS platforms.
5. Skip duplicates for all 4 pointers identically to 3 Sum.

---

## C++ Solution

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> res;
        if(nums.empty()) return res;
        
        int n = nums.size();
        sort(nums.begin(), nums.end());
        
        for(int i = 0; i < n; i++) {
            // Skip duplicates for the 1st element
            if(i > 0 && nums[i] == nums[i - 1]) continue;
            
            for(int j = i + 1; j < n; j++) {
                // Skip duplicates for the 2nd element
                if(j > i + 1 && nums[j] == nums[j - 1]) continue;
                
                // Calculate target for the remaining 2 elements (use long long to prevent overflow)
                long long target_2 = (long long)target - nums[i] - nums[j];
                
                int front = j + 1;
                int back = n - 1;
                
                while(front < back) {
                    long long two_sum = nums[front] + nums[back];
                    
                    if(two_sum < target_2) {
                        front++;
                    } else if(two_sum > target_2) {
                        back--;
                    } else {
                        res.push_back({nums[i], nums[j], nums[front], nums[back]});
                        
                        // Skip duplicates for the 3rd element
                        while(front < back && nums[front] == res.back()[2]) front++;
                        
                        // Skip duplicates for the 4th element
                        while(front < back && nums[back] == res.back()[3]) back--;
                    }
                }
            }
        }
        return res;
    }
};

int main() {
    Solution sol;
    vector<int> nums = {1, 0, -1, 0, -2, 2};
    int target = 0;
    
    vector<vector<int>> res = sol.fourSum(nums, target);
    for (auto& quad : res) {
        cout << "[" << quad[0] << ", " << quad[1] << ", " << quad[2] << ", " << quad[3] << "]\n";
    }
    return 0;
}
```

---

## Complexity Analysis

- **Time Complexity:** `O(N^3)`. Sorting takes `O(N log N)`. There are two outer loops `O(N^2)`, and the inner while loop takes `O(N)`.
- **Space Complexity:** `O(1)` auxiliary space.
